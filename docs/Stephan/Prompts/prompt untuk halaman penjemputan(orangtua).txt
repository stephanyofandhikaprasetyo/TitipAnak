[INFORMASI DATABASE & RELASI]
- anak (id, user_id, kode_anak, nama_lengkap, nama_panggilan, jenis_kelamin, tanggal_lahir, foto, kelas_id, alamat, catatan_medis, status_kehadiran ['belum_datang','hadir','dijemput','pulang'], jam_masuk, jam_pulang, is_active, timestamps, softDeletes)
- penjemput (id, anak_id, nama, hubungan, nik, no_hp, foto, is_active, timestamps)
- penjemputan (id, anak_id, penjemput_id, user_id, waktu_jemput, metode_verifikasi, foto_bukti, tanda_tangan, catatan, status, timestamps)
- users (auth bawaan Laravel - role Orang Tua)
- kelas (id, nama_kelas)

Relasi Model:
- anak: belongsTo(User::class), belongsTo(Kelas::class), hasMany(Penjemput::class), hasMany(Penjemputan::class)
- penjemput: belongsTo(Anak::class), hasMany(Penjemputan::class)
- penjemputan: belongsTo(Anak::class), belongsTo(Penjemput::class), belongsTo(User::class)

Pengerjaan akan dibagi menjadi 3 commit/tahapan utama. Saya akan memberikan referensi UI/HTML pada setiap tahapnya untuk disesuaikan ke dalam komponen Blade + Tailwind CSS:

1. COMMIT 1: Mengajukan Izin Penjemputan

3. COMMIT 3: Membatalkan Status Izin Penjemputan
   - Logic controller untuk membatalkan pengajuan yang masih berstatus 'pending'.
